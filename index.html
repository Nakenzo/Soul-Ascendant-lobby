PANDUAN PEMASANGAN

Langkah cepat untuk mulai bermain di perangkat pilihanmu

1

Cara Pasang di Android

Unduh file Soul-Essence.apk dari tombol di atas. Buka notifikasi unduhan, lalu jika diminta izinkan opsi "Pasang aplikasi dari sumber ini" di pengaturan keamanan Android. Tekan Install dan game siap dimainkan.

2

Cara Pasang di Windows PC

Unduh Soul-Essence-Setup.exe. Jalankan berkas pemasang, ikuti langkah wizard di layar sampai selesai. Ikon game akan muncul di desktop dan siap dijalankan dengan performa native tanpa emulator.

3

Cara Main di Web & PWA

Klik tombol Mainkan Versi Web. Game langsung terbuka di browser tanpa instalasi. Untuk menyimpan sebagai aplikasi offline di HP atau PC, klik tombol "Install App" di bilah alamat browser.
