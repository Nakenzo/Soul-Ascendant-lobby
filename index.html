PANDUAN PEMASANGAN

Langkah cepat untuk mulai bermain di perangkat pilihanmu

1

Cara Pasang di Android

Unduh file Soul-Ascendant.apk dari tombol di atas. Buka notifikasi unduhan, lalu jika diminta izinkan opsi "Pasang aplikasi dari sumber ini" di pengaturan keamanan Android. Tekan Install dan game siap dimainkan.

2

Cara Main di Windows PC

Unduh Soul-Ascendant.exe. Cukup klik dua kali berkas untuk langsung memainkan game tanpa proses instalasi berbelit. Game langsung menyambut dengan loading screen animasi dan performa 60 FPS native tanpa emulator.

3

Cara Main di Web & PWA

Klik tombol Mainkan Versi Web. Game langsung terbuka di browser tanpa instalasi. Untuk menyimpan sebagai aplikasi offline di HP atau PC, klik tombol "Install App" di bilah alamat browser.
